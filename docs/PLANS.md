## How to use execution plans

- Before starting non-trivial work, create a plan in `docs/exec-plans/active/`.
- Use the plan to record intent, steps, decisions made, and blockers.
- When complete, move to `docs/exec-plans/completed/` and update this index.
- Plans are versioned history — do not delete them.
